Enterprise SaaS Access Management System

Centralized Google Sheets dashboard for tracking employee software licenses, utilizing data validation and dynamic COUNTIF arrays for real-time headcount and access auditing.

The Problem

Tracking employee software licenses and access across multiple platforms (Google Workspace, Slack, monday.com) using scattered spreadsheets leads to shadow IT, missed offboarding revocations, and wasted license costs.

The Solution

Built an enterprise-grade, centralized SaaS Access Management dashboard in Google Sheets. It utilizes strict data validation, corporate-level formatting, and dynamic COUNTIF arrays to provide real-time visibility into active seats, pending onboarding, and suspended accounts.

Build Process

  • Step 1: Database Structure
    Created an Access Register with strict data validation chips for statuses and tool access.
  • Step 2: UI/UX Design
    Applied corporate minimalist styling, removing default gridlines and using semantic colors for quick visual auditing.
  • Step 3: Metrics Automation
    Engineered dynamic COUNTIF formulas to calculate active headcounts and license utilization.
  • Step 4: Audit Readiness
    Integrated a "Last Audit Date" tracking system for monthly compliance reviews.

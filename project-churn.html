Customer Churn Prediction Analysis

Wrote SQL queries to extract data, filter results, and run data quality checks on large datasets. Built a customer churn prediction model to find trends and submitted a detailed data report based on the results.

The Problem

Businesses often lose clients unexpectedly due to a lack of visibility into retention metrics, equipment aging, and customer behavior patterns.

The Solution

Developed as a final coursework report for the GCI Omnicampus April 2026 program, I conducted a comprehensive data analysis using SQL and Python to identify primary churn drivers. I built a Random Forest machine learning model to predict at-risk customers, achieving a solid ROC-AUC score and providing actionable insights for the retention team.

Build Process

  • Step 1: Data Extraction
    Wrote SQL queries to extract, clean, and join large datasets from multiple databases.
  • Step 2: Preprocessing
    Utilized Pandas in Python to handle missing values and encode categorical features.
  • Step 3: Model Training
    Built and trained a Random Forest Classifier to identify patterns in customer churn.
  • Step 4: Visualization
    Generated Matplotlib and Seaborn charts to present feature importance and actionable business insights.
